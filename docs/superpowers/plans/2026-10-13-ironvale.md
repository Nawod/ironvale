# Ironvale implementation plan

Goal: implement the approved complete single-player RTS. Spec: ../specs/2026-10-13-ironvale-design.md.

Architecture: pure TypeScript fixed-tick state machine, worker transport, PixiJS WebGL battlefield, React HUD, IndexedDB persistence. Shared balance tables. No network server.

## Tasks
1. Simulation foundation: types, definitions, seeded map, visibility, pathfinding, shared command validation. Tests: equal starts, determinism, blocked path, visibility, ownership.
2. Economy: recruitment, tasks, construction, repairs, population, drop-off, research, trade. Tests first for cost conservation, prerequisites, depletion, population, queues.
3. Combat/conquest: target selection, counters, ranged/siege attacks, stances, patrol, gates, garrison, occupied capital. Tests first for contest/reset, transfers, overpopulation, victory/defeat, rebuilding.
4. AI and snapshots: fair visible-world planner, attack/defense, all-vs-all rivals, worker serialization. Test deterministic AI runs, fog isolation, save/load continuation.
5. Battlefield/UI: original drawn sprites, animated entities, touch/desktop controls, responsive HUD, placement, audio, tutorial, menus, saves.
6. Validation/delivery: unit tests, headless matches, browser flows, screenshots, 400-unit performance, production build, documentation.

## Review focus
Stale commands/captured ownership; hidden targets and unseen enemy data; blocked spawn/path goals; save restoration of every subsystem; touch gestures conflicting with issuing orders.
